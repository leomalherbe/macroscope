# Usage de l'intelligence artificielle

*[English version](AI-USE.md)*

Macroscope est conçu et maintenu par Léo Malherbe. Son développement s'appuie largement sur un assistant d'intelligence artificielle : Claude, d'Anthropic, utilisé dans Claude Code.

**Modèles utilisés**
- Claude Fable 5.1 : du 2 au 7 novembre 2026.
- Claude Opus 5.5 : depuis le 7 novembre 2026.

**Ce que l'IA a fait, sur mes instructions**
- L'écriture du code : le moteur économique OPEN-MU, les pages (desk, board, console, page du modèle), le backend Google Apps Script et les tests automatiques.
- La documentation technique (spécification du modèle, README) et la traduction française de l'interface.
- Des propositions de conception (règles de jeu, options, visualisations), que j'ai acceptées, modifiées ou écartées.

**Ce qui relève de moi**
- La conception pédagogique du jeu, ainsi que le choix du modèle et de ses règles.
- Les décisions : toute modification passe par une demande de fusion (*pull request*) que je relis et que je fusionne moi-même.
- Les essais en classe et les corrections qui en découlent.

**Traçabilité.** Dans l'historique du dépôt, les contributions de l'IA sont signées « Co-Authored-By: Claude … » avec le nom du modèle.

**Pendant le jeu, il n'y a pas d'IA.** Les résultats sont calculés par le modèle économique, de façon déterministe ; aucune donnée de partie n'est envoyée à un service d'IA.

**Responsabilité.** Toute erreur qui subsiste, dans le code, le modèle, ses paramètres ou les textes, relève de ma seule responsabilité.

*Léo Malherbe, 14 novembre 2026*
